# Scoot Park

A 3D open-world freestyle scooter game that runs in the browser. Ride nine areas, chain tailwhips, bar spins, flips and grinds into combos, customise your scooter and rider, and tick off the challenges.

Play it: open `index.html` in a browser, or use the GitHub Pages link for this repo.

Controls: press **H** in the game for the full list. Keyboard or an Xbox-style controller both work, and controller buttons can be changed in Settings.

Built with [three.js](https://threejs.org/) r128 (included as `three.min.js`).
